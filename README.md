# Amphipoda Taxonomic Key 🦐

An interactive web-based identification tool for marine and estuarine 
Amphipoda (Crustacea) recorded from Thailand, with a focus on 
Gammaridea from the Gulf of Thailand and estuarine habitats.

## Features
- **Key to Species** — identify amphipod specimens to species level 
  by selecting morphological characters step by step
- **Key to Family** — for users unfamiliar with amphipod families, 
  a preliminary key narrows down the possible family before 
  proceeding to species identification
- Morphological traits organized by body segment for intuitive navigation
- Built from primary taxonomic literature and original specimen data

## Data Coverage
- Order: Amphipoda
- Suborder: Gammaridea
- Families: Aoridae, Corophiidae, Melitidae, Ampithoidae, and others
- Region: Thailand (Gulf of Thailand, estuarine and coastal habitats)

## Tech Stack
- Python 3
- Pandas
- Streamlit

## Usage
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data Sources
Taxonomic keys and species diagnoses compiled from published literature 
including works on Indo-Pacific and Southeast Asian Amphipoda. 
Species records based on field collections from Thai coastal habitats.
